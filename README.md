# Fastfetch Dotfiles

My personal [Fastfetch](https://github.com/fastfetch-cli/fastfetch) configuration for Linux.

## Installation

**1. Install Fastfetch**

Follow the instructions in the [official repository](https://github.com/fastfetch-cli/fastfetch).

**2. Clone this repository**

```bash
git clone https://github.com/USERNAME/fastfetch-dotfiles.git
cd fastfetch-dotfiles
```

**3. Install the configuration**

```bash
mkdir -p ~/.config/fastfetch
cp config.json ~/.config/fastfetch/config.json
```

**4. Run Fastfetch**

```bash
fastfetch
```

## Requirements

- Linux
- Fastfetch
